# Nordic Relic v0.3.3 — Design identity showcase

Open `index.html` in a modern browser. No build tools or dependencies are required. `tokens.css` provides dark and light semantic palette variables; `DESIGN-SPEC.md` is the complete, updated design document.

## What's new in v0.3
- Removed the barcode motif and replaced it with Nordic engraved geometry.
- All components use strictly square corners.
- Expanded component catalogue with eight approved families.
- Four interactive dialog previews: Edit, Confirmation, Manage HP, Detail.
- Dialog headers have no leading decorative icon.
- Focus containment, Escape handling and focus restoration for demo dialogs.

This is a standalone **design showcase**, not a production Angular library. Demo data is not persistent. Fonts load from Google Fonts when online and fall back to system fonts when offline.

## v0.3.2 extended specimens
Includes segmented controls, page tabs, multiselect, tooltip, alerts, notification banner, radio controls, contextual record search, sidebar pages and collapsing nested sidebar navigation. Open `index.html` and select “Extended controls” in the navigation.
