# LazyDM product facts

Last verified: 2026-11-14

LazyDM is a desktop campaign manager and encounter tracker for Dungeon Masters. It brings campaign preparation and the tools used during play into one app.

## Availability

- Status: pre-1.0 and in active development
- Downloads: not available yet
- Supported operating systems: macOS, Windows and Linux
- Official website: https://lazydm.com/
- Official repository: https://github.com/Tratt0re/lazydm

## Campaign files

A LazyDM campaign lives in a user-owned folder called a Codex. Notes are plain Markdown and remain compatible with other Markdown tools, including Obsidian. LazyDM uses a local, rebuildable SQLite index for search and links; the campaign is not locked inside that index.

## Campaign preparation

- Markdown editor with Live preview, Source and Reading modes
- Wikilinks, incoming and outgoing Links, rename with link refactoring, and broken-link Review
- Templates driven by the campaign's game system
- A shared Compendium for copying system material into campaigns
- Images, audio and PDF assets
- Interactive maps with pins linked to notes
- Tabs and split screen

## Encounters

LazyDM includes an encounter manager with Combatants, initiative, health and temporary hit points, statuses with round tracking, a party roster, a battle bar and a cemetery for defeated Combatants. Tracker layouts are included for Generic campaigns, D&D 5e and Pathfinder 2e. Values can be overridden for one encounter without changing the linked note.

## Sync

The Codex can stay on the computer or live inside an iCloud, Dropbox, OneDrive, Box or Google Drive folder. The cloud provider performs the synchronization. LazyDM waits for placeholder files to download and warns about conflicting copies.

## Optional AI access

LazyDM can expose the Codex to an AI assistant on the same computer through an opt-in local MCP server. The server is off until the user enables it.
