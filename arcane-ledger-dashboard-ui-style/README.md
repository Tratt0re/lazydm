# The Black Ledger — Fantasy Brutalist D&D Dashboard

A standalone browser-based UI prototype mixing D&D motifs with brutalist editorial/industrial interface design.

## Start
Open `index.html` in a browser. No build step, framework, backend, or package installation is required.

## Source files
- `index.html`: markup and semantic structure
- `styles.css`: colors, layout, responsive design, typography
- `app.js`: sample data and interactions

## Features
- Party and encounter stat panels
- Initiative order with next-turn and reset controls
- Chronology / field reports, including new entries
- Modular dungeon mini-map and resource indicators
- Responsive desktop/mobile layout

All data is fictional and stored only in memory; reload resets the prototype. Navigation and period controls are concept demonstrations, not distinct data views. Google Fonts are loaded if online; local system fallbacks work offline.
