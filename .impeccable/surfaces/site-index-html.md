# Surface brief: LazyDM landing page (index.html)

Mode: Persuade. Visitor: a Dungeon Master (often an Obsidian user) deciding whether to follow or try LazyDM.
Action: Follow on GitHub (downloads are "coming soon"; no releases exist). Proof: the real feature set, drawn with the
app's own tokens; no testimonials, counts, prices or licence claims.

Chosen structure (decision page, user pick): "One long note". Visual world is inherited from the app (ArcTechUI tokens,
Barlow Condensed / IBM Plex Sans / IBM Plex Mono, square, bronze accent, dark + light).

Memorable moment: the theme switch re-themes the whole note and every sample live; the code map tracks the scroll.

Unresolved (do not invent): licence and price wording, repository visibility, real screenshots, Franco mascot treatment.

## Direction contract

THESIS: The whole site is one LazyDM note in Live preview, a document the visitor reads like a campaign page, refusing the
marketing-page arrangement of hero, icon-card trio and testimonial strip.

OWN-WORLD: The app's own bronze-on-mineral palette in both themes (#101114 / #1A1C1F canvas and card, #B9A27A bronze; #E9EAE7 /
#FAF9F6, #6D5A3E in light), square corners, 1px steel borders, condensed display titles ending in a bronze dot, mono labels,
a collapsed Properties box, an Info box with a status bar, ◇ dividers, a code map on the right edge. Recognisable with the
copy removed.

STORY: A DM understands in one screen that this is a notes app they own plus the tools for the table, believes it because the
page is itself plain Markdown-shaped, and follows the repository.

FIRST VIEWPORT: Top bar like the app header (breadcrumb "lazydm / index.md", links, Dark / Light / Auto switch). Below it a
single readable column (about 44rem): Properties box, a huge "LazyDM." title, a two-sentence lede, the Follow on GitHub
primary action beside a quiet "Download: coming soon" status, then the pre-1.0 Info box. Code map at the right edge from
1180px up.

FORM: One long note, dealt card 2 of 3 (index 3 of the grounded list), seed: seed:66b50ae82aba3d94.
